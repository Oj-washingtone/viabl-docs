<Update label="v1.2.0" description="July 2026">
**New MDX components & design tokens**

Added `<Color>`, `<Color.Row>`, and `<Color.Item>` components to showcase brand colors and design system tokens. Features click-to-copy clipboard functionality with visual feedback overlays, support for direct string props (`light` and `dark`), and side-by-side preview panels for theme-aware color pairs.

Added `<Tree>` and `<FileTree>` components to render interactive file hierarchies with automatic extension-based file icons, collapsible folders (`Tree.Folder`), file items (`Tree.File`), keyboard navigation, and direct Markdown bullet list parsing.

**Platform targeting & download controls**

Added `<Platform>` component to conditionally render OS-specific content based on browser detection or user selection.

Added `<PlatformSelector>` component for toggling active operating systems using tab bar or dropdown variants with smooth icon animations.

Added `<Download>` component to render platform-aware download buttons with customizable styles (`"block"`, `"outline"`, `"soft"`, `"ghost"`), colors, sizes, corner radius, and Lucide icons.

**Page layouts & sidebar customization**

Support for custom layout modes (`default`, `full`, `grid`, `landing`) in MDX frontmatter or `docs.json` tabs. Added `sidebar: false` frontmatter option to hide the left sidebar with automatic content width scaling from 3xl to 4xl.

**Global announcement banner**

Added `banner` configuration in `docs.json` to display global announcement bars with Markdown link support, predefined alert types (`info`, `warning`, `critical`), custom background colors, and persistent dismissibility.

</Update>

<Update label="v1.1.4" description="June 2026">
**AI assistant**

You can now add an AI assistant to your documentation. Configure a provider in `docs.json` and your users get a chat interface grounded in your docs content. Supports Anthropic, OpenAI, and self-hosted Ollama.

```json
  "ai": {
    "provider": "anthropic",
    "apiKey": "${ANTHROPIC_API_KEY}",
    "suggestedQuestions": ["How do I get started?"]
  }
```

All fields under `ai` support `${ENV_VAR}` interpolation to keep keys out of your repo.

**SEO and AI discoverability**

Viabl now generates a sitemap, `llms.txt`, and `robots.txt` automatically. Added `aiScraping` to `docs.json` to block known AI crawlers. Added `noIndex` frontmatter field to hide individual pages from search engines. Improved Open Graph support with proper image generation for social sharing.

**Navigation improvements**

The navigation configuration now supports three formats — legacy array, dictionary mapped to tabs, and raw string format for headerless sidebar items. Added `"all"` as a reserved key for persistent sidebar items that appear on every tab.

**Telemetry**

Viabl now collects anonymous usage data to help improve the tool. Telemetry is enabled by default and can be opted out at any time.

```bash
  viabl telemetry disable
```

To check the current status:

```bash
  viabl telemetry status
```

No personal information, file contents, or project names are ever collected. Only CLI commands, versions, platform info, and success/failure signals are tracked.

</Update>
