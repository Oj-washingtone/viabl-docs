## Overview

The `Columns` and `Column` components provide a grid system for structuring documentation pages. They allow you to place text, code blocks, cards, and media side-by-side with responsive breakpoint controls.

- **Columns**: A responsive grid container that manages column count, gap spacing, and vertical alignment.
- **Column**: An individual content wrapper with support for column spanning and sticky positioning.

---

## Example

<Columns cols={2} gap="gap-6">
  <Column>
    ### Left Column

    Add Markdown text, lists, or components on the left.

  </Column>
  <Column>
    ### Right Column

    Pair with code blocks, media, or sticky sidebars on the right.

  </Column>
</Columns>

## Props

### Columns (Container)

| Prop       | Type                                        | Required |  Default  | Description                                                                                  |
| :--------- | :------------------------------------------ | :------: | :-------: | :------------------------------------------------------------------------------------------- |
| `cols`     | `number \| string`                          |    No    |    `2`    | Number of columns on desktop (`1`, `2`, `3`, or `4` supported).                              |
| `gap`      | `string`                                    |    No    | `"gap-6"` | Tailwind CSS gap class for horizontal and vertical grid spacing (e.g. `"gap-4"`, `"gap-8"`). |
| `align`    | `"start" \| "center" \| "end" \| "stretch"` |    No    | `"start"` | Vertical cross-axis alignment of columns inside the grid.                                    |
| `children` | `React.ReactNode`                           | **Yes**  |     —     | One or more `<Column>` components or HTML/MDX elements.                                      |

### Column (Item)

| Prop       | Type               | Required |   Default   | Description                                                                               |
| :--------- | :----------------- | :------: | :---------: | :---------------------------------------------------------------------------------------- |
| `span`     | `number \| string` |    No    | `undefined` | Number of desktop grid columns to span (applies `lg:col-span-${span}`).                   |
| `sticky`   | `boolean`          |    No    |   `false`   | When `true`, pins the column near top of the viewport on desktop (`lg:sticky lg:top-24`). |
| `children` | `React.ReactNode`  | **Yes**  |      —      | Content rendered inside the column container.                                             |

## Responsive Breakpoints

Columns automatically stack vertically into a single column on mobile screens and expand into multi-column layouts on larger viewports:

| `cols` Prop | Mobile (< 768px) | Tablet (768px – 1023px) | Desktop (≥ 1024px) | CSS Grid Class Applied                      |
| :---------: | :--------------: | :---------------------: | :----------------: | :------------------------------------------ |
|     `1`     |     1 Column     |        1 Column         |      1 Column      | `grid-cols-1`                               |
|     `2`     |     1 Column     |        1 Column         |   **2 Columns**    | `grid-cols-1 lg:grid-cols-2`                |
|     `3`     |     1 Column     |        1 Column         |   **3 Columns**    | `grid-cols-1 lg:grid-cols-3`                |
|     `4`     |     1 Column     |      **2 Columns**      |   **4 Columns**    | `grid-cols-1 md:grid-cols-2 lg:grid-cols-4` |

---

## Usage Notes & Best Practices

- You can use dot-notation `<Columns.Column>` as a direct static attachment instead of importing `Column` separately.
- Always combine `sticky` with `align="start"` on the `<Columns>` parent container so child columns can scroll independently.
- When placing code blocks inside columns, ensure long lines wrap or scroll horizontally to maintain layout integrity.
