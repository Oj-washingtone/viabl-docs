## Overview

The `Color`, `Color.Row`, and `Color.Item` components provide a visual showcase for brand colors, design system tokens, and theme-aware color palettes. Swatches feature automatic click-to-copy functionality for instant developer workflow integration.

- **Color**: The top-level grid or table wrapper container.
- **Color.Row**: A categorized group container for organizing swatches into named sections.
- **Color.Item**: An individual color swatch displaying a visual preview, token name, hex/RGB values, and copy feedback.

## Color

The main container component. Supports two layout variants: `"compact"` (a 4-column responsive grid) and `"table"` (a grouped card container for `<Color.Row>` items).

`Color.Item` -- Individual color swatch blocks. Accepts standard color strings (Hex, RGB, HSL) or theme-aware object pairs for light/dark mode tokens.

<Tabs>
  <Tab title="Output">

      <Color.Item name="Brand Blue" value="#2563EB" />
      <Color.Item name="Brand Dark" value="#0F172A" />

## Props

**Color component**

| Prop       | Type                   | Default     | Description                                                                                   |
| :--------- | :--------------------- | :---------- | :-------------------------------------------------------------------------------------------- |
| `variant`  | `"compact" \| "table"` | `"compact"` | Overall container style (`"compact"` for a grid layout, `"table"` for categorized card rows). |
| `children` | `React.ReactNode`      | Yes         | The `Color.Item` or `Color.Row` components to render inside.                                  |

**Color.Item component**

| Prop    | Type     | Required | Description                                                        |
| :------ | :------- | :------- | :----------------------------------------------------------------- |
| `name`  | `string` | Yes      | The label or token name displayed on the swatch.                   |
| `value` | `string` | No       | Single Hex, RGB, or HSL color string (e.g. `"#3B82F6"`).           |
| `light` | `string` | No       | Light mode color string for theme-aware tokens (e.g. `"#ffffff"`). |
| `dark`  | `string` | No       | Dark mode color string for theme-aware tokens (e.g. `"#090d16"`).  |

**Color.Row component**

| Prop       | Type              | Required | Description                                                |
| :--------- | :---------------- | :------- | :--------------------------------------------------------- |
| `title`    | `string`          | Yes      | Section title heading displayed above the row of swatches. |
| `children` | `React.ReactNode` | Yes      | `Color.Item` swatches to group under this row.             |

## Accessibility Notes

- Clicking any Color.Item automatically copies the color string (or value.light) to the clipboard.
- Visual checkmark feedback is briefly displayed upon successful copying.
- Ensure color contrast ratios meet WCAG standards when choosing token pairs.
